DESCRIPTION (590):
80% of callers sent to voicemail hang up without a message; the rest wait ~8 hours to be heard.
This replaces the beep with an AI attendant and puts every message on the desk phone:
• AI attendant takes a structured message (who, matter, urgency, callback window)
• Whisper transcription + GPT summary, priority flag, auto-routing
• Pushed to Cisco / Yealink / Poly phones via real CiscoIPPhoneMenu / CiscoIPPhoneText XML — one softkey to call back
• Web inbox with transcript, summary, matter, assignee; hang-ups get an auto text-back
